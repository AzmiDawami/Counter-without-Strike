# Counter (without) Strike
Bukan nama game, melainkan aplikasi penghitung sederhana yang berbasis website

# 🚀 Panduan Penggunaan

## 1. Membuka Aplikasi
- Unduh atau clone seluruh file proyek ini.

- Pastikan file index.html, style.css, dan script.js berada dalam satu folder yang sama.

- Buka file index.html menggunakan browser pilihan Anda (Chrome, Firefox, Edge, Safari, dll).
Atau anda juga bisa membukanya [di sini](https://counter-without-strike.netlify.app/)

## 2. Cara Menggunakan Fitur
### Menambah Counter Baru

- Klik tombol + (Floating Action Button) di pojok kanan bawah.

- Isikan nama counter pada kolom yang tersedia (maksimal 30 karakter).

- Klik tombol Simpan atau tekan tombol Enter.

### Mengoperasikan Counter
- (+) (Tambah): Menambah nilai counter sebesar +1.

- (-) (Kurang): Mengurangi nilai counter sebesar -1.

- Reset: Mengembalikan nilai counter ke angka 0.

### Mengedit & Menghapus Counter
- Edit Nama: Klik ikon pensil ✏️ pada kartu counter, ubah namanya, lalu klik ikon centang ✔️ untuk menyimpan.

- Hapus Counter: Klik ikon tempat sampah 🗑️, lalu konfirmasi penghapusan pada pop-up konfirmasi yang muncul.

### Mencari & Membersihkan Pencarian
- Ketik nama counter pada kolom pencarian di bagian atas.

- Klik tombol Cari atau tekan Enter.

- Klik tombol silang ✕ di dalam kolom pencarian untuk menghapus kata kunci dan menampilkan kembali seluruh counter.
